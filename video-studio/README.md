# 動画スタジオ（MVP）

施工写真・動画を使い、15〜30秒の縦型リールを自動構成して一部を手直しする、端末内処理のWebアプリです。

## 起動
GitHub Pages / Cloudflare Pages などの静的配信で `/video-studio/` を開いてください。ビルド・APIキー・ログインは不要です。HTTPのローカルファイル直開きより、HTTPSでの配信を推奨します。

## 実装済み
- 写真・動画の一括取込（写真10、動画3、合計200MBまで）
- 施工紹介 / Before・After / 写真付き作業記録の自動構成（ルールベース）
- クリップの役割、順番、表示時間、動画開始位置、字幕、拡大率、位置調整、ズーム
- 元に戻す / やり直す（最大15履歴）
- キャンバス再生プレビュー
- BGM持込・音量設定（保存は端末内）
- IndexedDBへの自動保存・再読込時の編集再開（ブラウザ環境依存）
- 720p / 1080p、MediaRecorderによる実時間動画書き出し、共有 / ダウンロード
- 端末の対応コーデックに応じてMP4またはWebMを判定

## 技術的な制限と注意
- **MP4が必ず出るわけではありません。** 出力形式はブラウザのMediaRecorder機能検査結果に依存します。音声付きMP4でAAC対応が明示できないブラウザではWebMを優先します。
- 実時間書き出しのため、画面ロックや別タブへの移動時は中断します。iPhone Safariの書き出しは**実機未検証**です。
- 元動画の音声は含めず、BGM音源だけを追加します。
- 動画のカット精度は端末のデコードと描画タイミングに依存します。高解像度動画、HDR、HEIC/HEVC/MOVは端末によって読み込みできない場合があります。
- 取り込んだ素材はアップロードしません。IndexedDBはOSのストレージ整理やブラウザデータ消去で失われる可能性があります。
- 自動構成は内容認識AIではありません。役割は編集画面から手動で指定してください。
- 顔やナンバープレートの自動モザイク追従、場面内容の自動解析、動画元音声のミックスは未実装です。**公開前に個人情報・BGMの許諾を確認してください。**
- 写真・動画の元ファイルは編集処理で書き換えません。

## 動作確認済み
- Chromium系ブラウザのヘッドレステストにて、写真3枚 → 15秒自動構成 → H.264 MP4生成を確認
- 動画を含む構成とBGMを含む出力（ブラウザによりWebM）を確認
- 動作確認はテスト端末・テスト素材によるものです。iPhone実機での検証が残っています。

## 実機チェック
1. iPhone Safari 27系で写真を取り込み、15秒動画を保存できるか
2. HEIC、MOV（HEVC/HDR）、縦横混合素材の表示
3. 1080p出力の音声・映像同期、編集画面との字幕一致
4. 共有画面から「ビデオを保存」が選べるか
5. 再起動後にIndexedDB保存を復元できるか
6. ブラウザ非対応形式のエラー表示、画面ロック時の中断動作

## 実装方式
バンドル不要のHTML/CSS/JavaScriptで独立しています。端末内でCanvasに描画し、MediaRecorderでMP4かWebMにエンコードします。Remotionやサーバー処理を組み込む前の実機検証用MVPです。
